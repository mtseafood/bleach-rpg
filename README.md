# BLEACH Text Adventure RPG

純私人娛樂使用。

---

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `BLEACH_RPG_SYSTEM.md` | 完整系統設計文件（詳細版，供參考與擴充） |
| `PROMPT_READY.md` | **直接貼入 AI 的精簡版 Prompt** ← 從這裡開始 |
| `ZANPAKUTO_GENERATOR.md` | 斬魄刀生成器（單獨使用） |

---

## 快速開始

1. 打開 `PROMPT_READY.md`
2. 複製中間 ``` 內的所有內容
3. 貼入 Claude / GPT 等 AI 的對話框
4. AI 會開始引導你建立角色

---

## 建議使用的 AI

- **Claude**（推薦，長文理解最佳）
- ChatGPT-4o
- Gemini 1.5 Pro

---

## 系統特色

- 護廷十三隊完整資料（隊長、副隊長、斬魄刀）
- 斬魄刀生成系統（刀靈人格、精神空間）
- 完整靈壓數值體系
- 始解→卍解成長樹
- 虛進化路徑（普通虛→特大虛→破面）
- 滅卻師神聖文字系統
- 完現術者系統
- 勢力聲望系統（護廷各隊分開計算）
- 真央靈術院入學系統
- 6個不同世界時間點可選
- 死亡後果真實（不保護玩家）
